無料・登録不要のWebアプリ / オープンソース

アニメまとめ

外部APIから今季・過去のアニメ情報を自動取得し、一覧・集計・週間放送スケジュール・ 国内の配信状況として表示するWebアプリです。画面本体は依存ライブラリなしの 単一HTMLファイル、配信情報は日次バッチで生成した静的JSONを読み込む構成です。

デモを開く ソースコード 登録不要・そのまま操作できます

できること

01

今季アニメの自動取得

アクセスした日付から放送シーズンを自動判定して一覧表示。前季・来季・歴代トップ・年別ベストにもワンタップで切り替わります。

02

条件を組み合わせた抽出

年（1960年〜）×季節×並び順×放送形式×ジャンル×最低スコア、さらに作品名のキーワード検索。過去作品も同じ画面から探せます。

03

取得結果の自動集計

件数・平均スコア・放送中本数に加え、ジャンル / 制作会社 / 原作媒体の分布をその場で集計してグラフ表示します。

04

週間放送スケジュール

今週7日分の放送予定を曜日別に時刻順で表示。深夜帯は放送業界の慣習に合わせ、朝5時始まりの24時制（25:30＝翌1:30）で表記します。

05

国内の配信サービス表示

dアニメ・Prime Video・U-NEXT・Netflix など、日本で視聴できるサービスを作品ごとに表示します。6,152作品分を収録しています。

06

日本語のあらすじ

元データのあらすじは英語のみのため、日本語版Wikipediaの導入部を照合して表示します。出典を明記し、英語の原文にも切り替えられます。

07

マウスオーバーで拡大表示

カードにカーソルを合わせると、バナー画像・スコア・配信サービス・次回放送を含む拡大パネルが浮き出ます。

08

詳細情報とお気に入り

放送期間・次回放送日時・制作会社・原作媒体・PV・公式サイトを表示。気になる作品は端末内に保存し、週間表を登録作品だけに絞れます。

09

条件をURLで共有

絞り込み条件と表示タブがURLに入るため、そのまま共有・ブックマークできます。ブラウザの戻る操作にも対応しています。

10

オフラインでも閲覧可能

通信できないときは直近の取得データに自動で切り替え、いつ時点の情報かを明示します。復旧時はワンクリックで最新に戻せます。

技術構成

構成
画面本体は単一HTMLファイル（約1,200行）。HTML / CSS / JavaScript のみで、外部ライブラリもビルドも使っていません。
作品情報
AniList GraphQL API。作品一覧と放送スケジュールの2種類のクエリをフィールド定義共有で構築しています。
あらすじ
日本語版Wikipedia API。完全一致 → 季数を除いた題名 → 検索の3段階で照合し、誤マッチを抑えています。
配信情報
TMDB API（提供元は JustWatch）。GitHub Actions で日次取得し、静的JSONとして配信します。
キャッシュ
localStorage に6時間保持。APIのレート制限（30リクエスト/分）対策と再訪時の高速表示を兼ねています。
表示
CSS Grid によるレスポンシブ対応（PC / タブレット / スマートフォン）。OSのダークモード設定に自動追従します。
動作環境
Chrome / Edge / Firefox / Safari の現行版。インストール不要です。

配信情報の設計

配信情報の取得にはAPIキーが必要ですが、公開ページにキーを置けば誰でも読み取れてしまいます。 そこで実行時にAPIを呼ばず、バッチで生成した静的データを読む構成にしました。 キーはCI側の秘密情報として保管され、公開物には一切現れません。表示も速いままです。

実装で工夫した点

  • API制限を前提にした設計

    同一条件のリクエストはキャッシュから返し、スケジュール取得はページ単位の逐次読み込みにして、取得できた分から順に画面へ反映します。

  • 障害時に画面を白紙にしない

    通信失敗時は期限切れキャッシュへ自動フォールバックし、取得時刻を添えて通知します。オフライン・接続失敗・レート制限をメッセージで区別します。

  • ドメインの慣習に合わせた日付処理

    深夜アニメの「放送日」は暦日と一致しないため、朝5時始まりで日付を区切り、24時以降の表記に統一しています。

  • 保存領域の枯渇に耐える

    localStorage の容量超過時は古いデータから破棄して書き込みを再試行。保存が使えない環境でも機能を落として動作を継続します。

  • 外部データの安全な描画

    APIから受け取った文字列はすべてエスケープしてから描画し、HTMLを含む説明文はタグを除去したうえでテキストとして表示します。URLパラメータの値も選択肢と照合して検証します。

  • 複数データ源の突き合わせ

    作品情報・配信情報・あらすじは提供元が異なるため、ID対応表と題名の正規化で紐付けています。続編表記や記号の揺れを吸収し、一致しない場合は誤った情報を出さずに省略します。

  • 認証情報を公開物に含めない

    APIキーが必要なデータはCI側で取得し、生成物だけを公開します。鍵は秘密情報として保管され、ブラウザに配信されるファイルには現れません。
