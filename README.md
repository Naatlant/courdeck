# アニメまとめ

外部API（[AniList](https://anilist.co)）から今季・過去のアニメ情報を自動取得し、一覧・集計・週間放送スケジュールとして表示するWebアプリです。

- **デモ**: https://naatlant.github.io/anime-matome/
- **アプリ本体**: https://naatlant.github.io/anime-matome/anime.html

サーバー・ビルド・APIキー・外部ライブラリはいずれも不要で、`anime.html` をブラウザで開くだけで動作します。

## 機能

| 機能 | 内容 |
| --- | --- |
| 今季アニメの自動取得 | アクセス日から放送シーズンを判定して表示。前季 / 来季 / 放送中の話題作 / 歴代トップ / 年別ベストをプリセットで切り替え |
| 絞り込み | 年（1960年〜）× 季節 × 並び順6種 × 放送形式 × ジャンル × 最低スコア × キーワード検索 |
| 自動集計 | 件数・平均スコア・放送中本数、ジャンル / 制作会社 / 原作媒体の分布 |
| 週間放送スケジュール | 今週7日分を曜日別・時刻順に表示（朝5時始まり、深夜は24時制表記） |
| 詳細表示 | あらすじ、放送期間、次回放送日時、制作会社、PV、公式・配信リンク |
| お気に入り | localStorage に保存 |
| オフライン対応 | 通信失敗時は直近のキャッシュへ自動フォールバックし、取得時刻を表示 |

## 技術構成

- 単一HTMLファイル（約840行）／ HTML + CSS + JavaScript のみ、依存パッケージなし
- AniList GraphQL API（`media` / `airingSchedules` の2クエリ、フィールド定義は共有）
- localStorage による6時間キャッシュ（APIのレート制限 30req/分 対策）
- CSS Grid によるレスポンシブ、`prefers-color-scheme` によるダークモード対応

## ローカルでの実行

```
git clone https://github.com/Naatlant/anime-matome.git
```

`anime.html` をブラウザで開くだけです（ローカルサーバー不要）。
